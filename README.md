# Geo Newbiepinger

**Geo Newbiepinger** is an Android application that uses **Wi-Fi Direct** and **Augmented Reality (AR)** to enable **offline communication** between Wi-Fi-enabled Android devices — even when there is **no internet access** through cellular data or Wi-Fi access points.  

With **Augmented Reality**, you can visually locate your friends without internet or offline maps. Whether you’re on a **hike, skiing trip, camping in a forest, or relaxing at the beach**, Geo Newbiepinger helps you communicate and find your friends — completely offline.

---

## Getting Started

The `build` folder includes the signed `.apk` file. You can **sideload the app** by copying the file to your Android device and installing it manually.  

> **Note:** Ensure you have enabled **installation from unknown sources** on your device.

### Enable Unknown Sources

To allow installation from unknown sources:

- **Android 8.0+ (Oreo and later):**  
  - Go to **Settings → Apps → Geo Newbiepinger → Install unknown apps**  
  - Toggle **Allow from this source**  

- **Android 4.0 – 7.x:**  
  - Go to **Settings → Security → Unknown sources** and enable the option  

- **Android 3.x and earlier:**  
  - Go to **Settings → Applications → Unknown sources**
